RECAST Benchmark 题目介绍

本仓库用固定题目评测历史代码检索和项目交付。当前的 PolyCodeEval 题组覆盖五种语言，每个项目各有一道全项目骨架题（L1）和一道双模块补全题（L2），共 10 道。

PolyCodeEval 题目历史库与评分其他评测系列环境与复现

PolyCodeEval 的五个项目

每题提供需求文档、工程骨架、可读参考和可写文件清单。同一项目的 L1、L2 使用相同的外部行为验收，区别在于需要补全哪些模块。下列题号可以直接传给 bench:poly -- --task。查看题目定义

Logistics · 物流管理

C++ · 54 项黑盒用例

实现一个交互式物流系统。用户可以注册、充值、寄件和签收，重启后还能查到原有的账户和运单。

L1
补全账户、快件、物流服务和命令行四个模块。poly-cpp-logistics-l1
L2
补全快件实体和物流服务，接入已有账户类与命令行。poly-cpp-logistics-l2
验收
寄件扣费、运单编号、签收状态、按角色查询，以及终端输出的数值格式。

IDCenter · 分布式 ID

Java · 53 项黑盒用例

为命令行工具提供两类 ID 生成器和 Base62 编解码，使调用方能生成 ID、还原编码并读取时间信息。

L1
补全 Base62、IdWorker、SidWorker 和 CLI。poly-java-idcenter-l1
L2
实现 Base62 与 Snowflake IdWorker，接入已有 SidWorker 和 CLI。poly-java-idcenter-l2
验收
编码往返、连续生成 ID 的顺序、时间戳解析、SID 长度和 CLI 行为。

zxcvbn · 密码强度估计

Python · 41 项黑盒用例

给定密码和用户输入，识别词典词、重复、序列和日期等模式，估算猜测次数，并返回强度分数、破解时间和改进建议。

L1
补全 scoring、matching、time_estimates 和 feedback。当前模块顺序先实现评分，再实现会调用评分器的匹配逻辑。poly-py-zxcvbn-l1
L2
基于已有匹配和评分结果，实现破解时间估算与反馈。poly-py-zxcvbn-l2
验收
弱密码与强密码评分、用户输入匹配、不同猜测速率的时间估算，以及日期等模式的反馈。

EJS · 模板引擎

JavaScript · 119 项黑盒用例

实现 CommonJS 模板编译器，让程序和命令行都能把模板与输入数据渲染成文本。

L1
补全工具函数、编译与渲染引擎、CLI。poly-js-ejs-l1
L2
补全工具函数和渲染引擎，通过已有 CLI 调用。poly-js-ejs-l2
验收
XML 转义、自定义分隔符、嵌套模板的相对路径、命令行参数与文件输入。

gobreaker · 熔断器

Go · 45 项黑盒用例

实现支持泛型的熔断器，统计滚动窗口内的请求结果，驱动状态转换，并支持两阶段调用和跨实例共享状态。

L1
补全滚动计数器、核心熔断器、两阶段接口和分布式熔断器。poly-go-gobreaker-l1
L2
补全滚动计数器和分布式熔断器，与已有的核心及两阶段实现集成。poly-go-gobreaker-l2
验收
时间桶轮转与快进、成功和失败计数、半开状态、两阶段回调及分布式状态同步。

历史库与评分

L1 的五道题共享 LuaJIT、go-yaml 和 diff-match-patch 三个完整仓库快照。SAG2 从中索引了 209 个源码文件，共 127,999 个物理行，包含注释、空行和上游测试。每题还提供本项目的只读文件和专门编写的跨语言参考。L2 使用较小的参考池，其中有 11 个背景文件。历史仓库版本

整题通过要求完成 Git 交付并通过全部外部验收。用例通过率单独记录，能显示一次未完成交付已经实现了多少功能。对比方法包括单会话 rawagent、Codex CLI、按模块交付的 RECAST，以及加入历史代码检索的 SAG2-SQLite。

批次说明　poly-v4 收录 GPT-6 Luna 对五道 L1 题、四种方法的 20 次正式试验。当前工作区使用 poly-v5，调整了 Python 和 Go 的模块验收，待实现的后续模块可以留到整项目验收时检查。阅读 v4 正式报告 · 查看 v5 回归用例

仓库中的其他评测系列

  • S01–S10 · 检索与开发速度。十个构造场景覆盖支付校验、上传解析、订单封存、附件隔离、行情路由、索赔发件箱、维保计价、跨仓组件组合、多模块订单交付和大规模干扰检索。记录必需模块是否召回，以及交付骨架的用时。场景与结果
  • B01–B09 · 索引规模。从单语言小仓逐步扩大到 Camel 和多仓组合，比较全量建库、增量更新与冷暖查询。九组语料定义
  • project-delivery · 小型 JavaScript 工程。三道题分别实现订单批量入账与审计、租户索赔扣款与原子发件箱、带租约和重试调度的作业队列。题目与交付结果
  • real-v2 · 万行级多语言工程。三个任务分别交付 Django 国际化目录、coverage.py 的 HTML 执行上下文浏览器、BullMQ 优先级队列功能。题目与交付结果
  • large-v3 · 十万行级 Django 工程。在同一个 Django 仓库分别实现管理后台关联字段自动补全、slug 预填、设置或禁用密码，联动验证 Python 后端与 JavaScript 前端。题目与交付结果

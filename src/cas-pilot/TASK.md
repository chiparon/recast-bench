# 任务：恢复 SymPy 符号计算引擎

交付可在 CPython 3.12 和 mpmath 1.3.0 上离线运行的 SymPy 1.14 Python 包。用户应能通过现有的 `import sympy`、顶层公开 API 和对应子包获得与 1.14.0 相容的计算结果。使用当前工作区内的实现完成运算。保留函数参数、返回的表达式类型、精确域、简化语义和错误行为。题包中的函数签名、文档字符串及其示例与现有调用方共同描述接口。

| 功能范围 | 交付行为举例 |
|---|---|
| 多项式、数论与组合 | 在整数、有理数和有限域中做多项式算术、分解、GCD 与 Gröbner 基计算；完成模运算、因数分解、置换及置换群操作。 |
| 矩阵与张量 | 精确行列式、消元、特征值与线性方程组；数组操作、索引置换和收缩。保留矩阵的尺寸、元素域和奇异情形。 |
| 函数、化简、集合与方程 | 构造和化简初等与特殊函数，在给定假设和域上解方程、不等式，处理符号解集、交并和条件。 |
| 积分、极限、级数与离散求和 | 定积分和不定积分、发散和收敛情况、单侧极限、渐近展开、带上下限的符号和与积，以及微积分分析。 |
| 几何与输出 | 处理点线、多边形及交点关系。让运算结果通过原生打印接口输出，包括字符串、排版与代码打印。 |

允许编辑 `writable.json` 列出的 Python 文件中的实现。寻找 `CAS reconstruction TODO` 定位空缺。原生包初始化所需的一部分实现已保留。可浏览同级 `../history/` 中独立项目的源码，从中检索适用的算法。可使用 Python 标准库、给定的 mpmath 和题包中的现有代码。提交应自包含，调用其他 CAS、本机已有的完整 SymPy 或外部服务不属于交付方式。

从本目录用 `python -B smoke.py .` 运行公开示例。评测端另外运行固定的上游回归用例，按功能组报告成绩，并提供完整子包回归入口。例如，多项式分解后应能重新展开为原式，精确解应可代回方程。实现可以采用相容的其他算法，按行为验收。
